# Moderator guide (analyst console)

Run the console: see the main README. Each tab:

| Tab | What to do | How often |
|---|---|---|
| Number reports / Account reports | Approve real scam reports, reject spam or revenge reports | Daily |
| Disputes | Ask the owner for proof; **Uphold** clears the listing | Within 3 working days |
| Training data | Label shared messages Scam / Safe; **Discard** any that still contain names or personal details | Weekly |
| Official directory | Verify each entry on the organisation's own website and paste that page as the source. Add customer care numbers, SMS sender names (e.g. `GTBank`), websites, WhatsApp numbers | Start now, then monthly |
| Scam warnings | Publish a short warning when a new scam is going round (check "Trending in scans") | When needed |
| Partner feed | Download moderated indicators for partners under a data-sharing agreement | On request |

## Building the official directory

1. Start with the 20 most-used banks and fintechs, the 4 telcos, and NIMC, CBN, EFCC, NCC.
2. For each: the customer care number(s), WhatsApp number, SMS sender name, website(s), support email.
3. Only use the organisation's own website or app as the source, never a blog or social media post.
4. The seeded websites (from the scam engine) start **unverified**: verify or deactivate each.

Verified phone numbers are also sent to phones with call protection, so a call
from an official number shows "official number", with a reminder that caller ID can be faked.
